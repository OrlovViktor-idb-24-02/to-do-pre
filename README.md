# Сервис To-do

Добавление, копирование, удаление и редактирование задач с сохранением в localStorage. Вёрстка предоставлена Яндекс Практикумом.

Откройте index.html в браузере. Enter завершает редактирование, Escape отменяет изменение. Пустые задачи не добавляются.
